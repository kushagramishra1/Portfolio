# Kushagra Mishra | Portfolio

A responsive personal portfolio built with React, TypeScript, Tailwind CSS, and Vite. The site presents selected projects, technical skills, education, and experience in a clean, recruiter-focused layout.

## About

I am a Computer Science graduate with a focus on building full-stack web applications, user-centered interfaces, and practical product experiences. This portfolio is designed to help recruiters and collaborators quickly understand my experience, technical capability, and work style.

## Highlights

- structured project storytelling with role, stack, and impact
- clear experience and education sections
- responsive layout for desktop and mobile viewing
- strong call-to-action for email contact and resume access

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

Then open the app in your browser at the local Vite dev URL.

## Production Build

```bash
npm run build
```
